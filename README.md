# 在线影视 · 安装包发布

本仓库只放编译好的安装包，不含源码。

## 下载

在 [Releases](../../releases/download/latest/zaixian-yingshi.ipa) 里下载最新版
`zaixian-yingshi.ipa`（滚动更新，链接固定），用 TrollStore 或 Sideloadly
等方式自签安装。

## 这是什么

纯播放器外壳，不带源、不登录、不用后端：点播源、直播订阅、音乐台、电台
都由使用者自己在 App 里添加，只存在本机。覆盖安装保留数据，删 App 重装
后要重新添加。

- **影视**：设置里加源；含 `api.php` 的是接口源，其余是网站源（globe 图标，点开即网站）。
- **直播**：自加单个台；订阅 m3u/txt 链接整批导入；分组点标题折叠/展开；
  订阅左滑有更新、复制、删除。
- **音乐**：设置里加音乐台；填了账号密码的是 Subsonic 音乐台，都空着的是网站。
- **全球广播**：设置里加电台；流地址点台就播，网站链接点台就打开网站。
